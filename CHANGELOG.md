# Changelog

All notable changes to Illigma are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions will follow [Semantic Versioning](https://semver.org/) once code ships.

## End goal

**Illigma v1.0 (October 2027):** an open-source, local-first interface design tool with Figma's editing model. Your files stay on your machine. No account, no cloud and no seat licence.

v1.0 is done when a working product designer can build and hand off a multi-screen app design with a component library, entirely offline, without opening Figma. That means:

- **Core Figma parity** for the daily-use 80%: frames, auto layout, constraints, components and variants, variables and modes, styles, text, vector editing, prototyping and export.
- **Local-first files:** an open, documented `.illigma` format on disk, with autosave, crash safety and full history.
- **Performance:** 10k-layer files open in under 2 s and pan at 60 fps.
- **A way in from Figma:** import from Figma (REST API and best-effort `.fig`), SVG and Penpot, with 95% fidelity on a 50-file test corpus.
- **Developer handoff:** an inspect mode with code snippets, token export and a local MCP server for AI agents.
- **An open ecosystem:** a plugin API close enough to Figma's that common plugins port with small changes.

After v1.0: a Tauri desktop app in v1.x, then optional multiplayer (CRDT over LAN or a self-hosted relay) in v2. The full scope, roadmap and gates are in [docs/PRD.md](docs/PRD.md).

**Where we are now:** visual design phase. Development starts once the core editor states are designed and approved in Figma (see [docs/design/README.md](docs/design/README.md)).

### Added (2026-10-19, vector tools)

### Added (2026-10-19, snapping, smart guides, drop into frames and zoom)
- **Snapping and smart guides.** Moving, resizing and drawing snap edges and centres to sibling layers and the parent frame within 4 screen pixels, with 1 px guides; equal spacing snaps with gap pills; otherwise whole pixels. Ctrl (or ⌘) suspends snapping. Candidates are indexed once per drag, so 12,000 layers stay fast.
- **Drop onto a frame.** Dragged layers smaller than a frame drop into it (2 px outline while hovering; page position kept; one undo step). ⌘ drops a larger layer into auto layout, with the insertion line; Space keeps the parent; dragging out of a frame puts layers on the page, auto layout children included.
- **⌥-drag duplicates, and ⌘D repeats the offset** after duplicate-then-move.
- **⌥ measurements** to the hovered layer or the parent's edges.
- **Zoom:** ⇧2 zooms to the selection, ⌘+ / ⌘− step by powers of two, ⌘/Ctrl + wheel and pinch zoom around the pointer, and a plain wheel pans.

### Fixed (2026-10-19, QC round 8: text and export)
- **Text in a font that isn't loaded keeps its size.** Layout no longer measures it in Inter: moving it or its parent, or editing a sibling in its auto layout, left its width and height rewritten (and saved). `TextEngine.measure` returns null for a family it doesn't have, so the stored box stays, as Figma keeps text in a missing font. When local font permission was granted before, the file's own fonts on this computer load as it opens (not only when a text layer is selected); sizes are not rewritten when they arrive, the next edit that reaches the text measures it.
- **Editor shortcuts work while editing text.** ⌘S (saves now, keeping the typing first), ⇧⌘E, ⌘= ⌘- ⌘0, ⌘D and ⌘P reach the editor instead of the browser (Save Page As, bookmark, print, page zoom). The text input keeps only clipboard and word or line deletion keys (and Ctrl+letter on macOS).
- **An empty new text layer is never saved.** It isn't kept on blur, when a save settles open edits, or when an IME composition starts; reload, Back to files and closing the tab remove it with no undo step. Typography changes made to it before typing go into its "Add text" step. An IME composition in a new layer is one "Add text" step.
- **Typing is kept at least every 2 s**: continuous typing, or a long IME composition, is committed every 2 s (so it reaches the recovery journal and survives a crash), keeping the caret.
- **Inter's weights draw for real.** The bundled variable Inter drew every style as its default (Regular) instance, made bold synthetically, with Regular's widths; the text engine now sets the font's weight axis, so Thin to Black draw, measure and export at their true weight.
- **Enter and Space on a focused button press the button.** Enter on a Properties button (Font, Preset sizes, + buttons) no longer starts editing the selected text, and Space on a button focused from the keyboard presses it even with the pointer over the canvas. Single-key shortcuts are ignored inside dialogs, popovers and menus.
- **Deleting all of a layer's text and leaving it is one undo step** (one ⌘Z brings back the layer with its text).
- **Layer names from long text** are cut between characters, never inside an emoji.
- **Number fields take simple maths** (`12+12`, `3*4`, `(2+3)×4`), and `+2`, `*2` or `/2` change each layer's own value (Mixed too). Anything else is refused with a message instead of keeping its first number.
- **A cancelled export isn't a failure**: the dialog says what was written in a neutral note, keeps Export (and "Export the other N files"), and starts afresh when reopened.
- **Picking a local font while another edit runs** applies it when that edit ends, or says why it couldn't (instead of dropping it).
- **Font size and line height are bounded** in the format: font size above 0 and at most 10,000, a numeric line height 0 to 10,000. Files with values out of range open with them clamped (and a warning) instead of text that can never be edited; the text engine clamps too, and layout never stores a size that isn't finite.
- **Exports use fonts on this computer.** The export worker gets the font files the exported text uses; a family that isn't available is drawn in Inter, with the warning "Font “X” isn't available to export, so Inter was used."
- **Cancel works while files are written**: it stops between files and says "Export cancelled after K of N files. Written: …"; Retry writes the rest. A file whose write fails is removed if the export created it (no empty files left behind).
- **The Export card preview** redraws only when an edit reaches the previewed layer (its subtree, ancestors, or its page for "include overlapping layers"), waits behind real exports, and a newer preview replaces one still waiting.

### Fixed (2026-10-19, QC round 8: paint panels)
- **No hidden alpha in solids.** A gradient turned back into Solid (and a prototype file's `#rrggbbaa` or `rgba()` fill or stroke when imported) stores an opaque colour and puts the alpha in the paint's opacity, so the picker and the row show and edit all of it (it used to show 100 % for a fill that was half or fully transparent). Solids saved earlier with alpha in the colour show their real alpha (colour alpha × opacity); the first edit folds it into the opacity, in the same undo step.
- **Gradient stops.** A click on a stop only selects it: it no longer jumps to the pointer or adds an undo step. A drag starts after 3 px and keeps the point where the stop was grabbed. A stop moved past another with the keyboard keeps focus (each stop keeps its own element).
- **Drags always end.** Escape in a shadow's colour picker mid-drag, a lost pointer capture, or the card going away mid-drag now ends the drag as one undo step. Before, the edit stayed open: autosave waited, ⌘Z did nothing and later edits joined the drag.
- **Files dropped outside the canvas** (on a panel, the title bar) no longer open in the tab and leave the editor. Images are placed in the middle of the view; other files are refused with a message.
- **Images.** Several images dropped on the Fill card are one undo step (one image paint each, as in Figma). A drop or paste takes at most 50 files and 512 MB; files are hashed with the platform's native SHA-256 so the page stays responsive; images read while a drag is under way are placed when it ends (they used to be dropped without a word); every refused file is named, with its reason, in one message. Images, shapes and text placed into a rotated frame land where they were dropped or drawn.
- **Reordering paints.** Dragging the swatch whose picker is open moves the picker with its paint. Alt+↑ / Alt+↓ is in the swatch's description for screen readers, and the new position is announced.
- **Typed hex alpha.** `#rgba` in the picker and `#rrggbbaa` / `#rgba` in a Fill or Stroke row (and the shadow's hex) set the opacity; before, the alpha was dropped.
- **Damaged images.** An image whose header is right but whose data doesn't decode (a cut-short or corrupt PNG) is refused ("“Corrupt.png” can't be used: it isn't a readable image…") instead of being stored and drawn as an empty grey box.
- Tests: `packages/format/src/qc8.test.ts` (3), `apps/web/src/editor/paint/qc8.test.ts` (15), e2e `paint-qc8.mjs` (48 checks).

### Fixed (2026-10-19, QC round 7: tester fixes for the renderer and the web app)
- **Shadow spread on groups, text and frames without a fill is fast on CPU surfaces** (export and the CPU fallback canvas). Skia's morphology filter cost about a microsecond per pixel per pixel of spread there. Spread is now a chain of about log2(2 × spread) cheap passes (the maximum of the image and a shifted copy of itself, as `Lighten` on the alpha moved into opaque grey), matching Skia's result pixel for pixel; very large spreads and wide blurs run on a copy reduced by powers of two. Layers with effects are bounded by what they draw (recorded first), instead of covering the whole surface, and a shadow is knocked out only inside the layer's bounds. Inner shadows from pixels no longer go through an inverted, surface-sized image. On a 2000 × 2000 CPU surface: a group's shadow with spread 300 went from 72 s to about 30 ms per frame (300 ms at zoom 4, where it covers the whole surface); radius, spread and offset 1000 from about 180 s to 0.4 s; PNG export at 4x with spread 50 from 35.7 s to 0.6 s; PDF with spread 100 from 17.2 s to 0.3 s. On the CPU, layers with these effects are recorded for the zoom (rounded to a power of two) and recorded again when it changes. The GPU keeps Skia's own filters.
- **An 8000 × 8000 image fill no longer slows the canvas.** Images over 2048 × 2048 pixels are decoded off the main thread (`createImageBitmap`) and uploaded once as GPU textures, with half-size copies made on the GPU for when they are drawn small (they stand in for mipmaps, which Skia would rebuild for a texture on every frame). Panning over one: p50 100 ms → 16.7 ms, p95 133 ms → 16.8 ms; the longest task while opening the file: 366–813 ms → about 50 ms. The GPU resource cache budget is raised to 768 MB. New check in `perf.mjs`.
- **Text strokes are drawn**, over the fills: centred strokes as they are, inside and outside strokes at twice the weight cut to their side of the glyph outlines.
- **Images that couldn't be opened are reported.** Opening a file with a damaged or missing image, or a stray file in its package, shows a dismissable banner: "Some images couldn't be opened:" with the first three problems and how many more. New check in `canvas.mjs`.
- **An image added after a layer drew it as missing appears** (e.g. `Document.addImage` after the paint): the renderer listens for new images (`RenderSource.subscribeImages`) and re-records the layers that drew it as missing.
- `PageRenderer.layoutText` lines also give `ascent`, `descent` and `width`, so export can bound text exactly.
- **End-to-end runs can't hang.** A script whose step makes no progress for 120 s (`E2E_STEP_TIMEOUT`, scaled) fails with the step's name and a screenshot instead of waiting forever (Playwright's `page.evaluate` has no timeout of its own), and `run-all.mjs` stops a script that runs past 10 minutes (`E2E_SUITE_TIMEOUT`), browser included, and goes on with the rest. Closing the browser and the server can no longer hang a run either.
- Tests: 14 renderer tests (pixels against Skia's own filters, timing budgets, text strokes, layoutText, image levels, images added later), 4 web app tests, and e2e checks in `canvas.mjs` and `perf.mjs`.

### Fixed (2026-10-18, QC round 7: layers, resize and vectors)
- Layers panel: a selection made in the list keeps the row you're on in view; only selections made elsewhere scroll to the selection. Shift+↑, Shift-click upward and ⌘-click to deselect no longer scroll the list away, and Shift+Home from far down keeps keyboard focus in the list (↓ then moves in the list instead of nudging the canvas). Deleting the focused row moves focus to the next row (or the previous one), not to the page. Rows no longer claim `aria-expanded` while they can't collapse.

- SVG paths: an open subpath counts as enclosing an area only when its area isn't zero (`M0 0 h10 h10` doesn't). With the even-odd rule and overlapping subpaths, the closed subpaths keep their region (holes stay open) and an open subpath that encloses an area goes unfilled; otherwise every run fills as if closed, as in SVG.
- Tests: 11 unit tests, plus e2e checks in `canvas.mjs` and `perf.mjs`.
### Fixed (2026-10-18, QC round 7: images and hit-testing)
- **Images in big frames appear.** An image inside a top-level frame with more than 256 children (recorded in chunks), or on that frame itself, never showed: the frame wasn't re-recorded once the image decoded. It is now.
- **The canvas redraws when an image decodes**, with no click or pointer move needed (the editor passes `onImageReady`). New e2e check in `canvas.mjs`.
- **No more lost images on save.** Saves never remove image files. A damaged, oversized or misnamed image file Illigma couldn't load is left as it is (its layers keep the hash), instead of being deleted by the next save. Unused image files are removed only when a file opens with no recovered edits pending, and only sound ones (`ReadReport.unusedImages`, `Backend.collectImages`).
- **Images survive undo and crashes.** Saves write every image the document holds, so deleting an image layer, saving, undoing and crashing keeps the image. The recovery journal copies each added image (`Document.subscribeImages`) before the change lines that use it, so an image added after the last save comes back with Keep. With recovered edits pending, unused images on disk are loaded too.
- **Image size in pixels is capped**: 16,384 pixels a side and 64 megapixels, read from the PNG, JPEG, WebP or GIF header before decoding (`imageDimensions`, `imageSizeProblem`, `IMAGE_LIMITS.maxSide` and `maxPixels`). A 1.5 MB file of 20,000 × 20,000 pixels no longer makes the canvas allocate gigabytes: `addImage` refuses it, and opening leaves it out with a plain warning (and on disk).
- A save checks an image already on disk once per session (by hash) before skipping it, so a damaged copy of the same size is repaired.
- Reading a package retries when another tab removes a file between listing and reading it, instead of failing.
- The renderer frees decoded images no cached picture uses any more.
- **Hit-testing of aligned strokes**: on closed shapes, inside strokes are hit over their whole weight inside the outline, and outside strokes over their whole weight outside it (no phantom inner band). Rectangles, ellipses and frames can be picked on a centred or outside stroke past their box; a frame still clips its children to its box.
- The prototype importer warns when it keeps only a layer's first 100 effects. Opening a file hashes images with `crypto.subtle` (`readPackageWithReportAsync`, `sha256HexAsync`) instead of JavaScript on the main thread.
### Fixed (2026-10-19, export QC round 7: tester findings)
- **Text past its box** is no longer cut off. Export bounds use the renderer's line layout (`PageRenderer.layoutText`): the box, plus the last line's descent below it, and the glyphs above it when a tight line height lifts them. A 200 × 40 text box with three 20 px lines exports at 200 × 72 in PNG, JPG, SVG and PDF, as on the canvas. PDF group forms, effect images and the text image cover the whole text; SVG filter regions too. SVG without fonts measures the lines it writes. New: `textLinesBounds`, `TextBounds`, and an optional `text` argument to `exportScene` and `renderBounds`.
- **SVG shadow spread** keeps the shape: a shape's shadows with a spread are SVG shapes grown or shrunk from its outline (rectangles keep square corners, rounded corners and ellipses grow with the spread, as the renderer does; paths grow by a mitred stroke of twice the spread and shrink through a mask), then moved and blurred. An ellipse's inner shadow with spread 10 was a lens with square corners (`feMorphology` grows with a square). Inner shadows go over the fills and under the strokes, as on the canvas. Groups, text and shapes with a one-sided stroke still use `feMorphology`, with a warning that it is approximate.
- **PDF of several layers**: hidden ones are left out with a warning instead of failing the whole file; it fails only when every layer is hidden.
- **File names**: `uniqueFilename` makes a raw path safe first (direction overrides, illegal characters, `.` and `..`, device names), so no public path keeps U+202E or an unreserved COM¹. Device names with spaces before the extension ("CON .png") are reserved too; U+061C, line and paragraph separators, U+2066–206F and the byte order mark are dropped. The dropped characters are written as escapes in the source (they were invisible literals). Every public path (exportNode, exportNodes, planExportFilenames, exportPdf, uniqueFilename, sanitizeFilePart) is tested. On the main build at 33d9ef0, `exportFilename` and the batch already gave `RTL gnp.exe.png` and `_COM¹.png`.
- **Missing glyphs**: PNG, JPG and PDF exports warn, naming up to five characters, when text uses characters none of the loaded fonts has (they draw as empty boxes), checked with CanvasKit's `Typeface.getGlyphIDs`.
- Tests: 14 in `packages/export/src/qc7-tester.test.ts`.

### Fixed (2026-10-18, export QC round 7)
- **Phone photos** (JPEG Exif orientation) are no longer squashed or misplaced in SVG and PDF: the header reader turns the size for orientations 5 to 8, and the writers store the image as it is in the file (orientation tag cleared) and turn it themselves, matching CanvasKit and the PNG.
- **PDF JPEGs** (8-bit grey or RGB, baseline or progressive) are embedded as they are even when CanvasKit is loaded, instead of being re-encoded (a 282 KB photo made a 2.48 MB PDF). Other images are decoded only up to 16,384 px a side and 64 million pixels (checked from the header first), else left out with a warning.
- **Mitred corners and square caps** count in export bounds (a polygon's apex was cut by about half its stroke weight in every format, and so were SVG filter regions, PDF group boxes and effect images). The SVG mask for outside strokes reaches the miter limit too.
- **PDF effects budget**: layers with shadows or blurs are drawn at 2 px per pt (was 4) within 8 million pixels per file, at a lower resolution when they don't fit, and left out (with a warning) below 0.25 px per pt; image data is compressed at zlib level 6. Five 2,000 px layers with a 1,000 blur: 32.6 s to 1.5 s; 100 of them: over 10 minutes to 1.4 s (measured in Node). A layer with only background blur is no longer drawn as an image (the blur is left out with a warning).
- **SVG**: a filter, opacity or layer blend mode no longer shares an element with a stroke's clip or mask (the shadow was clipped) or with a paint's blend mode (the layer's was lost); they get a `<g>`. A NORMAL group whose children blend is `isolation: isolate`. Shapes cast shadows from their outline as opaque geometry, as the renderer does (a half-transparent fill made a half-strength shadow, and inner shadows covered the whole shape). ### Added (2026-10-18, gradients, images, effects and blend modes)

Layer blur, background blur (a backdrop filter clipped to the outline) and stroke alignment (clipped, at double width). Text draws once per visible fill, gradients included. ### Decided (2026-10-12)
- The name is "Illigma". The build starts from scratch: a TypeScript monorepo with a CanvasKit GPU renderer, an operation-based document model and our own layout engine.
- Web-first and offline-capable. Desktop app in v1.x. Multiplayer in v2.
- Licences: MPL-2.0 for the editor, MIT for the file-format spec and SDK, and AGPL-3.0 for the optional sync relay. A pure community project, with no paid plans.
- Dark theme first, with an original visual identity.

### Removed (2026-10-12)
