## Notes

- Almost all of this batch is cloud org/admin machinery (seats, billing groups, workspaces, SSO/SCIM, guest controls). Illigma has no accounts, so most rows are "Local: ..." equivalents. Only file/folder/page/version/preference behaviors are real editor requirements.
- Local-first wins we get for free: data residency, EKM, IP allowlists, session timeouts, and failed-payment lockouts all go away when files sit on the user's disk. The PRD should say that plainly instead of rebuilding these features.
- Hard limits worth matching or beating: canvas about ±130,000 per axis; folders nest 10 deep; autosave checkpoint every 30 min; Starter keeps 30 days of history and 3 files/pages. Illigma should have unlimited history and no file caps.
- Figma's formats (.fig/.jam/.deck/.buzz/.site/.make) are proprietary and "may change". A documented, open, diff-friendly file format is a key differentiator. A local copy drops comments and history, and its components become new mains, so Illigma's format should embed history and stable component IDs.
- Lazy page loading (only the current page loads) is how big files stay fast. Illigma's on-disk format should allow loading one page at a time.
- Version history details to copy: named versions (Cmd+Opt+S, title clipped at 25 chars), restore that adds checkpoints rather than overwriting, duplicate-from-version, "restore from version" for files too heavy to open, and library publishes logged as versions.
- Shared fonts (.TTF/.OTF, Skip/Replace on duplicate family) map neatly to a workspace `fonts/` folder that loads without system install. That also covers Linux/Chromebook, which was one of Figma's stated reasons for the feature.
- Library governance (approved check marks, enabled-by-default per file type, default variable mode per team/workspace, override hierarchy) maps to a workspace config file. Library analytics (inserts, detaches, per-asset usage, 1-year retention) needs a local scanner that walks the workspace. That is feasible but non-trivial, because Figma counts insertion events, not static instances.
- Color management (sRGB vs Display P3, Assign vs Convert, per-file profile, export profile) and keyboard-layout remapping (15 layouts) are easy to miss but matter for pro users. Both belong in v1.x.
- Collaboration-heavy features (connected folders, transfers, ask-to-edit, user groups, @group mentions, notifications) only apply if Illigma ships an optional self-hosted sync relay. SSO/SCIM/audit logs would only matter for that relay.
