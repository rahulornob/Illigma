## Notes

- Hard limits worth mirroring: tables cap at 500 cells (FigJam and Slides, CSV import truncates), timer max 99:59 with one per file, comments max 5 attachments and 100 per hour, custom palettes max 9 colors, rotation snaps to 15 degrees in FigJam.
- FigJam has no layers panel and uses a curated, constrained model: 4 typefaces, 5 text size presets (16/24/40/64/96), fixed sticky/highlighter palettes, thin/thick strokes only. A whiteboard module can reuse the Design engine but needs its own simplified object model and toolbar.
- Smart objects carry most of the build cost: auto-growing stickies, connectors with snapping/rerouting/5 endpoint styles, mind maps with child/sibling quick-create, tidy-up grid with drag-to-reorder and swap, and sections with lock-all vs background-only.
- Mermaid.js paste-to-diagram is a cheap, high-value, fully offline feature for an Illigma whiteboard module.
- Import from Miro, Mural, Lucid and Jamboard works by parsing their PDF exports and mapping objects heuristically. That runs fully offline but means writing a PDF-to-object converter. RTL text, italics and sticky bullets are dropped.
- Many FigJam features depend on real-time presence (voting, spotlight, cursor chat, emotes, high fives, audio with captions, open sessions). Locally they need a LAN or peer-to-peer sync layer, or must wait for P2. Timer and music can work solo.
- Slides is effectively Design plus a deck model: slide rows and groups, template styles (color and text styles you can remix), skip flags, slide numbers, transitions (8 styles plus easing/spring curves), and per-object animations (one per object, on-click or after-previous sequences).
- Slides interop formats to support: PPTX import (fonts forced to Inter; videos, tables, diagrams and animations dropped) and export (editable or flattened; gradients become solid), plus PDF export with sRGB or P3 and a native .deck file. A local-first .deck-like single-file format fits Illigma well.
- Figma Slides already has a "Make available offline" presenting mode, which shows offline presenting is a real user need. Audience live interactions (polls, alignment scales, stamps) need hosted multi-user state, so they should stay P2 for Illigma.
- Link previews and embeds (YouTube, Spotify, Figma, maps) and YouTube slide embeds need network access. In Illigma they should fall back to static bookmark cards when offline.
