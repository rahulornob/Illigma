## Notes

- Several articles are near-empty video wrappers (four "Advocate sidebar" pages, wrap-up quiz, course wrap-up); they contribute almost no feature content, only titles (e.g. sections vs groups vs frames).
- "Create a reusable list component" appears twice in the batch (Projects and Components collection) with identical content; rows were merged.
- Slots are new and complex: a slot is a property on a nested frame, cannot be on the component's top-level layer, accepts any layer type, supports preferred instances and default content, and has its own shortcut (Shift+Cmd+S).
- Override survival is tied to layer names and property names; Illigma's file format needs stable override keys, or renames must migrate overrides.
- Auto layout inference (flow, alignment, padding from current arrangement and Big nudge value) is a subtle behavior users expect from Shift+A.
- Duplicate memory (repeat offset and rotation) and duplicate placement rules (top-level frames go to the right in free space) are small but noticeable behaviors.
- Fixed-position layers re-anchor constraints to the prototype viewport, not the frame; Canvas stacking (First/Last on top) affects sticky nav rendering.
- Create multiple components caps at 100 per operation; plugins' loadAllPagesAsync can take 20-30 s on large files, which suggests lazy page loading for big local files too.
- Plugin compatibility (manifest.json, `figma` global, postMessage UI bridge, loadFontAsync rule) is a large surface; a compatible local plugin host would unlock the existing ecosystem.
- Cloud-dependent items (libraries publishing, branching, analytics, Community publishing/review, copy prototype link, mobile app viewing) need local-first equivalents such as linked library files, git-style branches and LAN preview.
