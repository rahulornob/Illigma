## Notes

- Almost everything here is cloud-only (accounts, profiles, social, review queue, Stripe payments). For local-first Illigma, the useful core is a **portable package format**: manifest (name, tagline, description, category, up to 5 tags of 25 chars or fewer, author, contributors, support URL, license), cover image (1920 x 1080), icon (128 x 128), preview images, and a bundled example/playground file.
- Licensing defaults matter for an import/export flow: free files and slide templates use CC BY 4.0 (attribution required, not public domain), and free plugins/widgets use a custom free license with no redistribution. Illigma should write a LICENSE into exported packages and show it on import.
- Duplicate semantics to copy: an import is a snapshot with no history, comments or permissions, gets a "(Community)" style name suffix, and does not live-update.
- The plugin trust model is worth adopting locally: manifest-declared network access (Unknown/Unrestricted/Restricted/None), a running-plugin toast, plugin name/icon in iframe headers, one plugin at a time with no background execution, and an offline notice requirement.
- Widget updates are not automatic; they need an explicit "Update to latest version" that migrates widget data and can be undone. A local widget runtime needs versioned state migration.
- Shaders (open beta) need WebGPU, allow only one animated/interactive shader running per page, can be keyframed in Motion, and are reviewed for unbounded loops and texture-sample cost. Shipping a local shader runtime means building a sandbox plus a cost linter.
- Mesh gradient (16 points, 4x4 grid, tessellation) is shipped as a shader fill but is a core-ish fill users expect, so I rated it P1. The other built-in shaders are P2 effects/fills.
- Marketplace limits for reference: $2 minimum price in whole USD, 15% fee, 30-business-day payout hold, one cash-out per week, subscription increases capped at +50% every 30 days with 16-day notice, 24 h automatic refund, 7-day default subscription trial, yearly discount of 1-95%.
- Hard to replicate locally: discovery, search with counts, likes/use metrics, follows, moderation and reporting. These need a hosted registry; an optional static Git-based plugin index could cover part of it later.
- The guidelines contradict each other on widget pricing: the selling guide says one-time only, while the widget publish flow offers subscriptions. Figma's review policy also bans general AI-chat/BYO-key plugins and MCP-exposing plugins, which a local-first, open tool can deliberately allow.
