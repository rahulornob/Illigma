## Notes

- Everything in this batch is a separate product surface (Sites, Make, Buzz, Motion), so nearly all rows are Module. A few have core-editor equivalents worth pulling into v1: the Actions menu (Cmd/Ctrl+K), theme, zoom shortcuts and canvas background color (P0). Keyboard a11y, the contrast checker, the missing-font alert and "Select all with same font" are P1.
- Sites' breakpoint model is the hardest part to build. Primary-breakpoint edits cascade with per-property overrides in secondaries. Secondaries can't reparent, and deleting there only hides. A local Sites module needs an override layer per node per breakpoint.
- Sites limits: video 300MB per file and 1GB per site; animated GIF/WebP max 50 megapixels (w x h x frames); CMS 200 items and 100 fields per collection; CSV import under 2MB, UTF-8, Title and Slug required; subdomain max 63 chars.
- Figma Sites cannot export site code. A local-first Illigma Sites module that exports a static HTML/CSS folder would be a clear advantage. Publishing, subdomains, custom domains, passwords and hosting all reduce to "export, then deploy anywhere".
- Code layers (Sites) and Make run arbitrary React/TS/Tailwind with npm installs and a Vite build. Offline, this needs a bundled JS runtime/bundler and a package cache. AI chat needs a bring-your-own model or API key.
- Make's local-codebase mode (.figma/make setup/install/dev/verify/env scripts, dev server preview, commit per prompt, branches and PRs) maps naturally to a local-first design. It is the closest Figma feature to Illigma's philosophy.
- Buzz bulk create (CSV/XLSX mapped to text and image layers, image URLs or images embedded in XLSX cells) and the Bulk edit spreadsheet (drag-to-fill, range edit) are pure data-binding features. They are buildable offline, apart from Google Drive URLs and AI fill.
- Buzz template guidelines (lock layers, editable-field panel, pink outline, Remove guidelines) amount to a permissioned-editing layer on top of components and variables. Without accounts, it can be implemented as file-level "template mode" locks.
- Motion: keyframes on any property, with Bezier presets (7 named plus Hold), springs (Gentle, Quick, Bouncy, Slow, custom Bounce) and cubic-bezier y-values allowed outside 0-1. Also motion paths with Cmd-drag curve handles, anchor point (Motion measures X/Y from the anchor, not the top-left), path trim 0-100% on center strokes only, per-unit text stagger, and audio (AAC/MPA/MP3/WAV) with split at playhead (Option/Alt+K).
- Make's "Copy design" (live DOM to editable layers with variable binding) and Code Connect-based paste of components as instances are hard but high-value bridges between a code module and the design canvas.
