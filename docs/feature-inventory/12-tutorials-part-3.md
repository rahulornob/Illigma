## Notes

- Most tutorial value is in small behavior rules a clone must match: Smart animate matches layers by name plus hierarchy, Cmd+D repeats the last offset, component sets are named from "name/variant" frame names, and groups' bounds leave out stroke overflow while booleans include it.
- Agent examples are capped at 200 per library. They are marked by a page named "Examples" or a "_example" name suffix. Guidelines files are attached per library in Design but kept per file in Make.
- AI Rename layers only renames layers that still have default names, so names users set are kept. Copy this rule if Illigma adds local AI renaming.
- Arc, polygon and star edits keep the original bounding box until you flatten. Flatten is destructive and removes container layers (frames, sections).
- Pattern fills stay linked to their source layer, keep working after the source is deleted, and the source must be in the same file. Illigma's file format needs to embed a snapshot of the source.
- Glass effect sets fill opacity to 20% automatically and refracts the layers underneath. That needs a real-time backdrop shader, which is hard to do in a lightweight local renderer.
- Motion module rules: timelines default to 2000 ms; playback can run once, loop or ping-pong; path trim works only on center strokes; only top-level frames export as animations; instance tracks can be moved in time but not edited.
- Prototype variables: a string variable bound to a variant property must match the variant's value names exactly, or Figma shows an error. Expressions support arithmetic, comparisons and if/else.
- Hard to build local-first: open sessions (24-hour guest access), audio calls, spotlight, synced music and timer, voting, @mentions with email, Check designs (Org/Enterprise), MCP connectors and web search. These need a sync layer or are out of scope.
- Shortcuts surfaced here: Shift+X swap fill/stroke, Shift+H/Shift+V flip, K scale, I eyedropper, [ send to back, Opt+Cmd+G frame selection, Opt+Shift+F flatten, Shift+P pencil, Shift+Delete delete-and-heal, Opt+R anchor point, Shift+E prototype tab, Shift+Space inline preview, Shift+Enter duplicate variable, Cmd+Opt+C/V copy/paste properties. FigJam: Shift+S section, S sticky, E stamp, M marker, / cursor chat, Cmd+Shift+K place image.
