## Notes

- Ellipse arc edits, polygon point counts and stars keep the original bounding box. Only Flatten refits bounds. Illigma has to match this to stay geometry-compatible.
- Text styles never store color, and the course says gradients must stay as styles. Those two rules split the token model between variables and styles.
- The default variant is whichever variant sits top-left in the set, and slash-named components like `type/hasColor` turn into variant properties when the set is created. Both are implicit rules that are easy to miss.
- Nudge values are stored per user, not per file. Preferences apply across all files, so Illigma needs a user-level settings store separate from the files on disk.
- Motion is a large module on its own: a timeline with a 2000 ms default, auto-keyframe, Hold/Back/custom-bezier/spring easing, anchor points, path trim (center strokes only), animated components with locked purple instance tracks, and animated export from top-level frames only.
- An MCP server fits local-first well. A local server with read and write tools (like `use_figma`) plus node-link scoping (Cmd L) would cover Figma's desktop MCP without the cloud. The remote MCP, seat limits and GitHub OAuth can be dropped.
- Code Connect UI needs GitHub OAuth and a published library. A local equivalent would map components to paths in a local repo, with per-component MCP instructions.
- Sites relies on breakpoint cascade from the primary breakpoint to the others, plus non-overlapping min/max width ranges. Sites also auto-assigns HTML tags (p/img/video/a/button). All of this is hard to rebuild and belongs in a later Sites module that exports static files.
- The AI features (agent chat, Make an image, Isolate/Expand/Erase/Upscale, shader fills and effects with generated UI controls, agent-built plugins, Weave tools) all depend on cloud models. Locally they would need BYO model keys. Remove background is the most feasible to do on-device.
- Most design-system and motion-theory lessons are guidance with no feature content. The rows that came from them cover only the concrete Figma behaviors they mention.
